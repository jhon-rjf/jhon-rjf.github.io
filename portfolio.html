의료 도메인 상담 에이전트

RAG, Agentic, QLoRA 3단계 진화

2025.02 ~ 현재 · 외부 협력 1인 개발 · 협력 의과대학 도메인 검증
  • 대상: 근감소증 환자·보호자 상담. 본인 건강 데이터와 검증된 가이드라인을 결합한 개인화 응답, 환각 통제가 핵심 요건
  • v1 RAG: LangChain + ChromaDB + BAAI/bge-m3, Llama-3.1-8B
  • v2 Agentic: ReAct 기반 Tool Calling 오케스트레이터 직접 구현, Anthropic MCP 명세 적용, 도구 6개에서 18개(진단·처방·종합 케어 3계층)로 확장, 4단계 파싱 fallback·자가복구 로직
  • v3 QLoRA: Llama-3.3-70B 4-bit QLoRA(r=32, alpha=64, all linear), 도구 사용을 가중치 수준에서 학습, distillation 멀티턴 도구 호출 대화 900개(train 767, valid 133)
  • 평가·인프라: RAGAS 4개 지표 기반 개선 루프, QC 회귀 테스트 27개, vLLM, PostgreSQL + TimescaleDB, Redis, MinIO
1차 파인튜닝 완료, 테스트 중. 초기 버전 KIIT 2025 하계 발표 [7]
